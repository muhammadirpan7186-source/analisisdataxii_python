📘 Materi: Dasar-dasar Python untuk Analisis Data

Mengapa Python Menjadi Raja Analisis Data?

Python adalah bahasa pemrograman tingkat tinggi yang sintaksnya sangat mirip dengan bahasa manusia (Bahasa Inggris sehari-hari). Dalam analisis data, Python digunakan untuk mengotomatisasi pembersihan, perhitungan, hingga visualisasi data dalam jumlah besar.

  • Ringkas & Mudah Dibaca: Tidak butuh simbol rumit seperti titik koma (;) atau kurung kurawal blok.
  • Ekosistem Kaya: Mendukung library profesional seperti Pandas, NumPy, Matplotlib.
  • Target Produk Kelas XII: Mampu menyusun skrip Python yang menerima kumpulan data, mengolah statistiknya, dan mencetak laporan keputusan otomatis.
Infografis: Alur Kerja Produk Python Analisis Data
Tahukah Kamu?

Nama bahasa pemrograman Python ternyata bukan berasal dari nama ular piton! Penciptanya, Guido van Rossum (1991), menamainya dari grup komedi favoritnya asal Inggris, "Monty Python's Flying Circus", karena ia ingin proses koding terasa menyenangkan dan tidak kaku.

Variabel & Tipe Data Dasar Python

Variabel adalah wadah penyimpanan data di memori komputer. Di Python, kamu tidak perlu mendeklarasikan tipe data secara manual karena Python mengenalinya secara otomatis (Dynamic Typing).

Tipe Data Kode Python Kegunaan dalam Analisis Data Contoh Variabel
Integer int Bilangan bulat (jumlah siswa, frekuensi, umur) jumlah_siswa = 36
Float float Bilangan desimal (rata-rata nilai, persentase, suhu) rata_rata = 87.65
String str Teks / kategori data (nama kelas, label predikat) kelas = "XII IPA 1"
Boolean bool Nilai kebenaran logika (filter data: lulus/tidak) is_lulus = True
Fakta Menarik

Kesalahan paling sering pemula saat mengolah data kuesioner adalah mencampur tipe data str dan int! Misalnya "85" + "90" di Python akan menghasilkan teks "8590" (penggabungan teks), bukan 175. Gunakan fungsi int() atau float() untuk mengonversi data angka terlebih dahulu!

Menyimpan Dataset dengan List dan Dictionary

Analisis data selalu berhadapan dengan banyak data sekaligus. Python menyediakan dua struktur utama yang wajib dikuasai:

1. List [ ... ]

Menyimpan sekumpulan data secara berurutan berdasarkan indeks (dimulai dari indeks 0).

nilai_ujian = [85, 92, 78, 95, 88]
print(nilai_ujian[0])   # Output: 85
print(len(nilai_ujian)) # Output: 5
2. Dictionary { key: value }

Menyimpan data berpasangan (kunci dan nilai), sangat mirip dengan kolom pada tabel Excel/JSON.

siswa = {"nama": "Aisyah", "nilai": 94}
print(siswa["nama"])  # Output: Aisyah
print(siswa["nilai"]) # Output: 94
Info Penting (Aturan Indeks Python)

Ingat selalu bahwa pengurutan (indexing) di Python bersifat Zero-Based (dimulai dari 0)! Jika sebuah List berisi 5 data, maka indeks validnya adalah 0, 1, 2, 3, 4. Mengakses indeks ke-5 akan memicu pesan error IndexError: list index out of range.

Mengolah Dataset Menjadi Produk Keputusan

Gabungkan fungsi bawaan Python (sum(), len(), max(), min()) dengan percabangan if-elif-else dan perulangan for:

produk_analisis_nilai.py Contoh Produk 
# Dataset nilai kuis analisis data kelas XII
data_nilai = [88, 92, 75, 96, 84, 90]

total = sum(data_nilai)
jumlah_data = len(data_nilai)
rata_rata = total / jumlah_data
tertinggi = max(data_nilai)

print("Jumlah Siswa :", jumlah_data)
print("Rata-rata    :", round(rata_rata, 2))
print("Nilai Puncak :", tertinggi)

# Logika pengambilan keputusan otomatis
if rata_rata >= 85:
    print("Status Kelas : SANGAT KOMPETEN")
else:
    print("Status Kelas : PERLU PENGAYAAN")
